# YouTube Music (No Ads) for Fedora / Linux

Launch YouTube Music as a dedicated standalone desktop application powered by Brave Browser for automatic ad-blocking and native account synchronization.

---

## 🚀 Features

- **Zero Ads:** Leverages Brave's built-in Shields to block video and audio ads automatically.
- **Account Sync:** Full access to your Google/YouTube Music account, history, and playlists.
- **Native Desktop Launcher:** Appears directly in your system application launcher with the official YouTube Music icon.

---

## 📥 Quick Install

Run this single command in your terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/Keshav272/youtubemusic-no_ads/main/install-ytmusic.sh | bash
```

---

## 🗑️ Quick Uninstall

To completely remove the application shortcut and icon from your system, run:

```bash
curl -fsSL https://raw.githubusercontent.com/Keshav272/youtubemusic-no_ads/main/uninstall-ytmusic.sh | bash
```
